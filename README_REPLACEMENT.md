# Frontend News e Catalyst entity-centric

File completi corretti per replacement in-place dalla root di `mip-frontend`.

Questa versione corregge anche la compatibilita TypeScript/MUI di `Typography`, passando `fontWeight` tramite `sx`.

```bash
cd /opt/mip/mip-frontend
unzip -o mip_news_catalyst_entity_match_frontend_v3.zip
npm run build
systemctl restart mip-frontend
```
